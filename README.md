# Journal Submission Title Page

A simple LaTeX template for creating the separate title page commonly required when submitting an academic paper to a journal.

The template includes fields for:

* Paper title and word count
* Author names, affiliations and contact details
* ORCID identifiers
* CRediT author contributions
* Corresponding-author information
* Acknowledgements
* Funding
* Declaration of interests

## Usage

1. Download or clone this repository.
2. Open the `main.tex` file.
3. Replace every red placeholder created with `\AddMore{...}`.
4. Add or remove author blocks as required.

Always check the target journal’s author guidelines, as required sections and wording may differ.

## Disclaimer

This template is a general starting point and does not guarantee compliance with any particular journal’s submission requirements.
